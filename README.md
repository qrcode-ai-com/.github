# QR Code AI organization profile

Public presentation of the [QR Code AI GitHub organization](https://github.com/qrcode-ai-com), where QR Code AI publishes its technology as open source.

The organization overview is maintained in [profile/README.md](profile/README.md). Its images are stored in [profile/assets](profile/assets); each one comes in a light and a dark version. The hero is an animated WebP with a GIF fallback, the other animations are GIFs and the still images are PNGs.

The package banners and journeys are animations. They are stored here so that they do not weigh on a clone of the engine. A banner quotes the first lines of its package's quick start or its channel's install commands, and a journey names its install command and its calls: render them again when that code changes. An integration banner shows how its host is used, with the names of the commands, menus and settings its README gives, and what the host gives back: render it again when those names change. The MCP, OpenClaw and skill banners name a version (0.3.1, 0.2.0): render them again when that version changes.
