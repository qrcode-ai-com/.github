# QR Code AI organization profile

Public presentation of the [QR Code AI GitHub organization](https://github.com/qrcode-ai-com), where QR Code AI publishes its technology as open source.

The organization overview is maintained in [profile/README.md](profile/README.md). Its images are stored in [profile/assets](profile/assets); each one comes in a light and a dark version. The hero is an animated WebP with a GIF fallback, the other animations are GIFs and the still images are PNGs.

The `mark-*` images and the destinations picture show the marks of the platforms where the packages are published. Those names and logos belong to their owners; they identify a destination and imply no endorsement.

Visit [qrcode-ai.com](https://qrcode-ai.com) to create QR codes and barcodes. The scanner source is in [qrcode-barcode-scanner](https://github.com/qrcode-ai-com/qrcode-barcode-scanner).

Product questions and partnerships: [contact@qrcode-ai.com](mailto:contact@qrcode-ai.com).
